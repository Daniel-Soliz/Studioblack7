# Studio Black7 Android APK

Aplicativo Android do Studio Black7.

- O APK abre a versão oficial do site em uma janela de aplicativo.
- Serviços, loja, carrinho, painel administrativo e dados do Supabase continuam sincronizados com o site.
- Links externos como WhatsApp, Instagram, Google Maps e Mercado Pago são abertos pelos aplicativos/navegador adequados.
- O seletor de arquivos funciona dentro do painel administrativo para uploads suportados pelo site.

URL integrada:
https://daniel-soliz.github.io/Studioblack7/

O APK é gerado automaticamente pelo GitHub Actions e publicado em:
public/downloads/StudioBlack7.apk
